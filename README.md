
# Software Engineering Lab

A practical series exploring software engineering principles through
small, working projects.

The goal is to understand not just how to implement solutions, but
also why they work, how to test them, and what trade-offs they involve.

## Projects

| # | Project | Concepts |
|---|---|---|
| 01 | [MiniGrep](projects/01-mini-grep/) | String matching, algorithms, CLI design |

## Areas of Exploration

- Algorithms and data structures
- Clean code and modular design
- Testing and debugging
- Performance analysis
- Backend engineering and databases
- Concurrency and system design
- Reliability and fault tolerance

## Approach

Each project focuses on a practical problem and documents its
implementation, design decisions, testing strategy, and potential
improvements.

## Status

Actively building and documenting new projects.
